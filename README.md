# Error-Backpropagation

This demo is designed to help learners understand how backpropagation allows a neural network to learn the XOR problem. It makes the main stages of backpropagation visible, allowing learners to observe how input values move through the network, how neuron outputs and output error are computed, how the error is propagated backward to the hidden units, and how weight adjustments (ΔW) are calculated and applied.

By stepping through the learning process, learners can see how repeated weight updates gradually change the network's behavior as it learns the XOR task.
