# Error-Backpropagation

This demo is designed to help learners understand how backpropagation allows a neural network to learn the XOR problem. The demo exposes every
        learning phase. Learners can observe the path of input values as they
        travel through the network, see the output generated by each neuron,
        examine how output error is computed, track how that error is sent
        backward to the hidden units, and watch how the corresponding weight
        changes (ΔW) are derived and applied to revise the network’s weights.
